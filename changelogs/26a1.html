Versioning System

\n

We use the following versioning system:

For new releases:

\n 
<year><release_type_abbreviation><release_number>
\n

For patch releases

\n 
<year><release_type_abbreviation><release_number><patch_letter>
\n

Release types:

\n
Typerelease type abbreviation
Alpha releasea
Beta releaseb
April Fools' releasexd
Pre releasepre
Major releaser
Patch releasepr
\n

Versioning example:

\n
VersionType
26a1Alpha release 1
26a1aAlpha release with a patch
26pre1Pre release 1
