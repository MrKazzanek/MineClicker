v26a1 - First Public Version of the Game!

Date: 2026-06-27
Author: MrKazanek

Welcome to the first public release of our game, Minecraft Clicker! The game will continue to evolve and grow right before your eyes.

We know that the game is not yet playable. Instead of releasing a heavily bugged and unfinished experience, we have chosen a different development approach: gradually introducing new features over time. This allows us to focus on quality and continuously improve the game while avoiding rushed updates.

In this release, we have added the main menu, which currently serves as the foundation for future updates.

What's New?

  • Main Menu – Added the game's main menu.
  • Splashes – Added splash texts displayed next to the game's logo in the main menu.
  • Parallax Background – Added a dynamic background in the main menu that subtly follows the player's cursor.
