Settings Menu, Language Selection, and Much More - 26a4!

Update Date: 11.07.2026

Welcome to Alpha 26a4! This update introduces a fully functional Settings menu and the ability to change the game's language. We've also made several technical improvements, including enhancements to the appearance of the Debug Screen. As usual, this release also adds a few new splashes and fixes several bugs.

Settings Menu

The Settings menu can now be accessed by clicking the Settings button in the game's main menu. It currently includes three configurable options:

  1. Language – Allows you to change the game's language. English is selected as the default language.

  2. Splashes – Enables or disables the splash text displayed on the logo in the main menu. When disabled, the main menu logo switches to a version without the green splash banner. This option is enabled by default.

  3. Main Menu Background Movement – Enables or disables the parallax background effect, where the main menu background follows the mouse cursor. This option is enabled by default.

Your settings are saved locally in your browser using LocalStorage, allowing them to persist between sessions. Please note that some browsers may not fully support this feature.

Available Languages

The game currently supports two languages:
  1. English (Default)
  2. Polish

The game's language can be changed at any time in the Settings menu.


Improved Fullscreen Support

You can now toggle the game's fullscreen mode by pressing the [F11] key. Previously, fullscreen could only be achieved by changing the browser's zoom or display mode.


Mailbox V-Sync Removed

The V-Sync mode introduced in the previous version has been removed.

This system did not meet our expectations, as not all devices were able to handle it properly.


New Splashes

Three new splashes have been added, including two Easter eggs. We will reveal only one of them: "English or Polish?" - the only splash that has its own Polish translation! Can you discover the other two?


Progressive Web App 

The game can now be installed as a Progressive Web App (PWA), as long as your browser supports this feature.

Technical Changes

New Improved Debug Screen Design:

The Debug Screen has now been divided into two sections:

  • Left
  • Right

Additionally, the text no longer uses a full background rectangle. The background is now only displayed behind the text itself, while empty areas no longer have a background.

New Debug Screen Values and Categorization:

The Debug Screen has received new displayed values. The information shown on the screen has also been organized into categories, which are now displayed in the format [category_name].

The current Debug Screen layout:

Left Section:

No Category:

  1. FPS – Displays the current frames per second, with the new Frame Time value shown in parentheses.

  2. Uptime – New value showing how long the game has been running since launch.

[Display & Input]

  1. Viewport – New value showing the size of the game's canvas.

  2. Mouse Screen – New value showing the mouse position on the screen.

  3. Mouse World – New value showing the mouse position in the game world (currently displays the same values as Mouse Screen).

[Scene:x]
A category without additional values. The x represents the current location or state where the player is currently located.

[Settings]

  1. Language – New value showing the currently selected game language (EN/PL).

  2. Splashes – Shows whether splash texts are enabled or disabled.

  3. Parallax – Shows whether the parallax effect is enabled or disabled.

Right Section:

No Category:

  1. Engine – Displays the game engine used to create the game and its version.

[Performance]

  1. VRAM – New value showing the amount of VRAM currently used by the game.

  2. Draw Calls – New value showing the number of draw calls.

  3. Objects Drawn – New value showing the number of objects drawn in the current frame.

[Environment]

  1. OS – Shows the operating system the game is running on.

  2. CPU – Shows the processor used by the game, including the new Cores value in parentheses, which displays the number of CPU cores available.

  3. GPU – Shows the graphics processor used by the game.

Bug Fixes

#MCC05 - Fixed an issue where some elements were displayed too quickly.
